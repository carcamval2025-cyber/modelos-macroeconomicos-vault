# modelos-macroeconomicos-vault

Base de conocimiento de **Modelos Macroeconómicos** (Macro II, ESEN, Tercer Ciclo 2026) y sitio de
estudio publicado en GitHub Pages desde `docs/`.

- Punto de entrada para cualquier agente: `AGENTS.md`.
- Sitio: `docs/index.html` (portada) y `docs/tema-0N/` (un Tema por carpeta). Diseño "Capas del
  modelo": cada Tema es una capa del mismo modelo y cada color es una variable (Y, IS, x, sector
  externo, i). Estilo y comportamiento compartidos en `docs/assets/guia.css` y
  `docs/assets/guia.js`; fuentes propias en `docs/assets/fonts/` (licencia OFL).
- Sistema de diseño: `02 Curso/Sistema de Diseño HTML.md`.
