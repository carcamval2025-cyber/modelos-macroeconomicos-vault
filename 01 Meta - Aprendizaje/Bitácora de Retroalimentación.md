# Bitácora de Retroalimentación

Registro cronológico (más reciente arriba) de qué funcionó y qué no en cada material generado. El objetivo es que el aprendizaje de Claude como agente y el de Navas como profesor avancen juntos: cada entrada es un dato para ajustar el siguiente material.

## Plantilla de entrada

Copiar este bloque y llenarlo cada vez que haya retroalimentación sobre un material:

```
### [Fecha] — [Tipo de material] — Tema [N]: [nombre]

**Material:** [enlace o nombre del archivo, ver Índice de Materiales]

**Qué funcionó bien:**
-

**Qué no funcionó / qué corregir:**
-

**Causa probable:**
-

**Ajuste para la próxima vez:**
-

**¿Se agregó a Lecciones Aprendidas?** Sí/No — [cuál regla]
```
